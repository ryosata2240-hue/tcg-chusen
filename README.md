# トレカ抽選ボード

ポケモンカード・遊戯王・ワンピース・ドラゴンボールの抽選販売情報を15分ごとに集め、
「ネット完結」「札幌近郊で受け取り」「要確認」「札幌では不可」に分けて一覧ページにする。

- 情報元: 入荷Now（https://nyuka-now.com）
- `collect.py` … 収集してページを作る
- `template.html` … 一覧ページのデザイン
- `stores.json` … 札幌近郊に店舗があるチェーンの判定表（追加・修正はここ）
- `state/seen.json` … いつ見つけたかの記録（NEW表示用）
- `.github/workflows/update.yml` … 15分ごとの自動実行
